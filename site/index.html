What works today

LienCAM is in alpha. It works, and it has rough edges. Simulate your toolpaths and keep a hand near the E-STOP when running a machine.

Open by design

Open by design. Everything you make in LienCAM is yours, and it leaves with you. Models export as STEP and STL, sketches as DXF and SVG, programs as plain G-code, and your tools, machines, post-processors, macros, settings and projects as documented JSON. Inside, LienCAM uses whatever formats work best for it - but the way out is always an open, standard format that other software can read. No account, no cloud, no lock-in.

Why I built this

I'm a hobbyist. I've been designing and building 3D printers and CNC machines since 2013 - never for money, just because I love building things and sharing them with other people.

LienCAM started the same way. I wanted software for my machine that I actually own, from the sketch to the G-code to running the job - where no company can later decide that features I rely on, like rapid moves or a multi-tool job posted as one program, aren't mine to use anymore. I've been working on it since the end of April 2026 - well over 1,000 hours of my own time - and I held the first release back until I could run real jobs with it on my own machine, because I wanted it to be genuinely useful to you from day one.

I'm sharing it under the Apache-2.0 licence, so anyone can use it, change it, fork it and make it fit their own machine - the same way I've always shared my printer and CNC designs, native source files included.

It was built with a lot of help from AI coding assistants. I set the direction, made the design decisions, judged the results and tested it on real hardware; the AI wrote much of the code.

This is a passion project. I have a day job and a family, so I can't be a full-time developer on it. If it turns out to be as useful to you as I hope, and you're able to help, I'd love to build it with you.
