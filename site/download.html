Release notes and all releases

Opening an unsigned build

Windows SmartScreen and macOS Gatekeeper may ask you to confirm before opening LienCAM.

Windows

  1. Download the installer (setup) to install LienCAM, or the portable file to run without installing.
  2. Open the downloaded .exe. If SmartScreen shows "Windows protected your PC", select More info.
  3. Check that the file is the LienCAM download you chose, then select Run anyway. Follow the installer steps, or open the portable app.

The portable program can travel on a USB stick, but settings and saved app data stay in %APPDATA%\LienCAM on that PC, shared with an installed copy. Use backup and restore to move your setup.

Microsoft's SmartScreen guide

macOS

  1. On an Apple Silicon Mac (M1 and later), download the arm64 disk image. Open the .dmg and drag LienCAM into Applications.
  2. Try opening LienCAM. If Gatekeeper blocks the unsigned app, open System Settings, then Privacy & Security.
  3. Find the message about LienCAM and select Open Anyway. Confirm with Open, and authenticate if asked.

Apple's guide to opening apps

System needs

  • Graphics with WebGL2 support.
  • About 8 GB RAM recommended; larger models and simulations need more memory.
  • Choose the architecture shown beside your download: x64 or arm64.
