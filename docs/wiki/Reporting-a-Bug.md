# Reporting a bug

**If the machine moved when it should not have, press your E-STOP first.** Report afterwards.

## Open the bug form

[Report a bug](https://github.com/eclsnowman/LienCAM/issues/new?template=bug_report.yml) opens the form on GitHub (you need a free GitHub account). Questions and ideas belong in [Discussions](https://github.com/eclsnowman/LienCAM/discussions) instead.

## What the form asks for

- What kind of problem it is.
- The LienCAM version (Help > About LienCAM shows it).
- Your Windows version (or say it is not Windows).
- The controller you were using, and whether it happened on screen only, in the air, or cutting.
- Numbered steps to reproduce it, and what you expected against what happened.

## What to attach

- Your project file (`.camproject`). It is the single most useful thing you can attach.
- The posted G-code, if the problem is in the output.
- Screenshots.
- Any error text, and the text from the bottom console.

Zip them if GitHub refuses the file type. Please do not paste passwords, license keys or personal data.

## Questions and test reports

Check [Troubleshooting](Troubleshooting), [FAQ](FAQ) and [Known limitations](Known-Limitations), or post questions and successful machine test reports in [Discussions](https://github.com/eclsnowman/LienCAM/discussions).
