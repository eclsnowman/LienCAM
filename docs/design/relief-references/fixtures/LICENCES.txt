Relief test fixtures - sources and licences
============================================
Design and test references for the image-relief tool. Every file here is public domain
or CC0; none needs attribution, but the sources are recorded so anyone can check.
Rebuild everything with:  python make_fixtures.py

fixture-01-portrait-photo-lincoln.jpg   (1000 x 1288, 8-bit grey JPEG)
  Exercises: fine detail in a continuous-tone PHOTO; film grain (denoise); the
  "photo brightness is not shape" problem (dark coat outlines become trenches).
  Source: Wikimedia Commons, File:Abraham_Lincoln_O-77_matte_collodion_print.jpg
    https://commons.wikimedia.org/wiki/File:Abraham_Lincoln_O-77_matte_collodion_print.jpg
    (Alexander Gardner, 1863). Licence on Commons: Public domain (author died over
    100 years ago; published before 1931). Downscaled from the 1280 px Commons thumbnail;
    original kept as src/lincoln.jpg.

fixture-02-terrain-heightmap.png        (1200 x 1200, 8-bit grey PNG)
  Exercises: a TRUE height map with soft gradients, ridges and river cuts; 8-bit
  terracing on gentle slopes; Auto must not clip its peaks (no flat tops).
  Source: Wikimedia Commons, File:Hand_made_terrain_heightmap.png by Drummyfish
    https://commons.wikimedia.org/wiki/File:Hand_made_terrain_heightmap.png
    Licence on Commons: CC0 1.0. Grey channel taken, alpha dropped, resized from the
    1920 px Commons thumbnail (src/terrain.png is the 1600 px intermediate).

fixture-03-text-sign.png                (1600 x 800, 8-bit grey PNG, black on white)
  Exercises: TEXT and a border (two-tone artwork); the Auto rule "light background ->
  invert so the letters rise"; zero plane = background; thin strokes vs cutter size.
  Generated by make_fixtures.py for LienCAM - CC0 1.0. Font: Aileron Regular (bundled
  in Pillow as ImageFont.load_default), by Sora Sagano / dotcolon.net, CC0 1.0.

fixture-04-hammered-texture-16bit.png   (512 x 512, 16-bit grey PNG, tileable)
  Exercises: a repeating TEXTURE (hammered dimples); 16-bit input kept at 16-bit;
  tiling across a face with no seam.
  Generated by make_fixtures.py for LienCAM - CC0 1.0.

fixture-05-dome-rings-16bit.png         (768 x 768, 16-bit grey PNG)
fixture-05b-dome-rings-8bit.png         (768 x 768, 8-bit grey PNG, same heights)
  Exercises: SOFT GRADIENTS with known maths (cosine dome + 6 shallow rings + a slow
  ramp). The 8-bit twin shows terracing; a test can compare the two and measure it.
  Height (0..1) = normalise( 0.8*dome + 0.06*cos(12*pi*r)*dome + 0.12*x ),
  dome = 0.5*(1+cos(pi*r)) for r<1, r = distance from centre / half-width.
  Generated by make_fixtures.py for LienCAM - CC0 1.0.

The renders in ../numbers/ are made by the same script from these files (CC0).
