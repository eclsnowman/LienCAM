# Thread-mill test

Click the + (**Import geometry**) button in the Geometry section header and
open `Thread Milling Test - 3 holes 3 bosses.step`.
In **Tool Library**, choose **Import** and select
`Thread Mill Tools - Metric Test Set.json`. The part and matching library teach
inspection of internal and external thread features and thread-mill selection.

The library stores dimensions in mm and feeds in mm/min. Check actual cutter
dimensions, reach, pitch, feeds and speeds against your tooling and material
before creating operations. There is no saved project for this part, so you
create the stock, tools and operations for your machine and material. Made by
the project owner; Apache-2.0.
