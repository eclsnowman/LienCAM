# Tray

Click the + (**Import geometry**) button in the Geometry section header and
open `Tray.step`. Inspect the tray walls, pocket
and floor before choosing stock and machining operations. This teaches solid
STEP import and planning pocket access; it does not supply a computed toolpath.

There is no saved project for this part, so the stock, tools and operations
are yours to set for your machine and material. Made by the project
owner; Apache-2.0. The STEP header identifies the CAD exporter, not a model author
or a separate geometry licence.
