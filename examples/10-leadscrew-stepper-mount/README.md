# Leadscrew stepper mount

Import `Leadscrew_Stepper_Mount.DXF` or `Leadscrew_Stepper_Mount.svg` using
**Import geometry**. They are alternative representations of the same mount;
import one at a time to avoid overlapping profiles. Inspect the closed profiles
and mounting holes before adding stock and operations.

This teaches DXF/SVG geometry import and profile inspection. No matching saved
project exists in the source sample set, so stock, tools and operations are yours
to set for the machine and material. Made by the project owner; Apache-2.0.
