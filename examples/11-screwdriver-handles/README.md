# Screwdriver handles

Use **Import geometry** to open `Screwdriver Handle Medium.step`.
This solid handle model teaches STEP import
and inspection of curved machining surfaces. Choose stock, workholding, tools
and roughing/finishing operations appropriate to your machine.

No matching saved project exists in the source sample set. Made by the project
owner; Apache-2.0. The STEP header identifies the CAD exporter, not a model author
or a separate geometry licence.

Source-set caveat: the file named `Socket Handle Screw Driver.step` currently
contains the same tray geometry as `../12-tray/Tray.step` (its STEP data section
is identical). It is withheld from the public export pending a corrected
socket-handle source; this folder currently teaches the medium handle only.
